# Mapa de publicaciones

Interactive map of Mexico for planning short-form travel content. In Spanish.

**Live site:** https://gleimbek.github.io/redes/

## What it does

- Clickable SVG map of Mexico's 32 states
- Each state opens a list of destinations (160 in total), each with a short note
- Mark a state as published, and see everything published so far in a table
- Progress is saved in the browser (`localStorage`), so it's still there the next time you open the page

## Built with

A single `index.html` with HTML, CSS and vanilla JavaScript, no build step.
